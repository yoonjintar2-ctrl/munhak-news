# 문학늬우스 '1분 문학' 영상 키트 (가로 일반 영상 · 쇼츠 겸용)

**용도(발행인 11/14)**: 사람들이 틀어 두고 문학을 들을 수 있는 영상. 1분은 컨셉일 뿐 길이는 내용대로 → 기본은 **가로 1920×1080 일반 영상**(`"format": "landscape"`), 본문 동안 오른쪽 아래 **원형 인서트에 연필이가 말하는 모습**(`img/mascot/video/talk.mp4`), 처음·끝은 연필이 전체 화면(`img/mascot/video/{hello,think,bow}.mp4`, 왼쪽에 서고 오른쪽에 말풍선). `"format": "portrait"` 이면 예전 세로 쇼츠 틀.

매일 지면의 **1분 고전·1분 현대문학**을 쇼츠 2편(세로 1080×1920, 길이는 내용에 맞게 — 발행인 11/14: "딱 1분 안 맞춰도 됨, 내용에 충실하게, 1분은 컨셉" · 쇼츠 한도 3분)으로 만든다. 채널: 유튜브 **문학늬우스(@munhaknews, yoonjintar2 계정)**.

## 발행인 지시(2026-11-14)
- 연필이(마스코트)가 **처음에 소개, 끝에 정리** — 그사이 본문은 그 작품의 **3초 삽화 영상**을 배경으로.
- 연필이 장면 배경은 **단색 그라데이션**(바닥·벽이 어딘지만 살짝 느껴지게) → `render.cjs --stage grad`.
- **자막은 나레이션에 맞춰 짧은 마디로 빠르게**(루즈하지 않게, 대신 읽을 시간은 확보).
- **쇼츠 UI 데드존** 피하기: 위 0~170px, 아래 1500px~, 오른쪽 940px~(버튼 열)엔 글자·액자를 두지 않음.
- 나레이션 = 마스코트 목소리(맥 qtts, Qwen3-TTS 복제), **차분한 톤**(배속 1.0, `scripts/tts/tts_post.py` 규칙으로 테이크 선택).
- 말풍선은 흰색, 글꼴 Pretendard, 글자는 말풍선 정중앙. 배경음악은 밝고 잔잔한 곡 하나를 낮게.
- 제목에는 해시태그. 첫 문장(첫 2초)에 연도·인물 같은 숫자/이름으로 시작.

## 본문 = 지면 줄거리 그대로 (11/14)
발행인: "쇼츠 나레이션이 사이트 작품 요약 텍스트를 전부 다 읽게" → `fill_body.py` 가 지면 story 문장을 그대로 body 로 채우고 자막 마디·장면 배경을 자동으로 잡는다. 1분 코너 지면 '듣기'도 이 나레이션 본문(`site_audio.py`) = 지면 글과 같은 문장. 가로 일반 영상이라 길이 제한 없음.

## 대본 형식 `shorts/scripts/<날짜>.json`
```json
{"date":"2026-11-14",
 "classic":{"title":"…","writer":"…","video":"img/<날짜>-classic.mp4",
   "intro":["1936년, 이효석. / 달밤 메밀밭, / …"],      // 연필이 말풍선(1문장)
   "body":["… / …", "…"],                               // 삽화 배경 + 자막(4~6문장)
   "outro":["… / …", "… / …"]},                         // 연필이가 정리·인사(2문장)
 "modern":{…}}
```
- `scenes`: `[{"from": 본문 문장 번호, "video": "img/<날짜>-classic-s1.mp4"}, …]` — 그 문장부터 배경이 그 장면으로 바뀜(국면이 바뀌는 대목마다, 대표 영상 `img/<날짜>-classic.mp4` 도 섞어 씀). 지면의 `classic.scenes`(문단 아래 장면 영상)와 같은 영상을 쓴다.
- ` / ` = 자막 마디 경계(한 마디 6~14자, 이름·제목은 한 마디 안에). 지면 줄거리(story·ending)를 따라 내용에 충실하게, 한 편 80~130초 안팎(본문 12~16문장). 맨 앞 `opener`("1분 만에 떠먹여 주는, 1분 문학!")는 두 편 공통.
- 저작권 있는 작품은 원문 인용 없이 내 말로. 결말은 다 말하지 않고 지면으로 유도해도 좋음.

## 만드는 순서
1. 대본 → 나레이션 작업 파일: 각 줄(` / ` 뺀 것)을 `tts_jobs.ko()` 로 한글화 + `" 음."`, 2테이크, 이름 `shorts-<날짜>`, id `<코너>_<번호 두 자리>_t<0|1>` → 맥 `~/Downloads/qtts/jobs/` (`.json.part` 로 쓰고 mv).
2. 맥에서 생성되면 `out/shorts-<날짜>/` 를 tar → stage → `/tmp/q/out/` 에 풀고 `out/casual1/E_think.wav` 도 같이.
3. `python3 scripts/shorts/make_short.py shorts/scripts/<날짜>.json classic /tmp/q . out-classic.mp4` (modern 도). `DRY=1` 이면 가짜 소리로 화면·자막 박자만 점검.
4. 검수: 몇 장면 캡처해 데드존 가림·자막 끊김·마스코트 동작 확인 → 전체 듣기.
5. 업로드(맥 크롬, 문학늬우스 채널로 전환 후 → 끝나면 샌디스크 올인으로 되돌리기), 제목에 해시태그.
