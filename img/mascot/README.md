# 마스코트 '연필이' (금로동 기자 후보)
세로 720×1280, 3초 반복, 컬러. 장면 소스: scripts/m3d/scenes/mascot/act-<이름>.js (모델: pencil.js)
다시 렌더: cd scripts/m3d && NODE_PATH=$(npm root -g) node render.cjs scenes/mascot/act-<이름>.js ../../img/mascot/pencil-<이름>.mp4 --w 720 --h 1280
