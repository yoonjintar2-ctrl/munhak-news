# 독자 신청 목록 (초안 작업이 맨 먼저 읽고 반영)

규칙: 신청작은 아래 '실을 날'에 맞춰 넣는다(그날 초안 D가 일치하면 반드시). 신청작 코너 JSON에 `"request": "독자 신청작"` 을 넣으면 지면 제목 옆에 꼬리표가 붙는다. 실었으면 이 표의 '상태'를 `실음(D)` 로 바꿔 커밋한다. 날짜가 지났는데 못 실었으면 다음 초안에 넣는다.
"번역이 잘 된 걸로"(독자 요청): 외국 작품은 원문(또는 공신력 있는 영역본과 원문 대조)에서 금로동이 직접 정성껏 옮기고 orig 에 원문을 붙인다. 기존 한국어 번역본을 베끼지 않는다. 시·소설 해설에 좋은 국내 번역본 하나를 '함께 읽기 좋은 번역'으로 소개해도 좋다(출판사·역자 확인한 것만).
